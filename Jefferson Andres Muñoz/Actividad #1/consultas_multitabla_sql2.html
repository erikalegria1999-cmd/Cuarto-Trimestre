COMPOSICIÓN CRUZADA

Producto cartesiano · CROSS JOIN

Combina cada fila de una tabla con todas las filas de la otra.

SELECT * FROM empleado CROSS JOIN departamento;
3 × 3 = 9 combinaciones
Aquí aparecerán las combinaciones.

COMPOSICIÓN INTERNA

INNER JOIN · buscar coincidencias

Devuelve únicamente los registros que tienen una relación válida entre las dos tablas.

SELECT * FROM empleado INNER JOIN departamento ON empleado.codigo_departamento = departamento.codigo;
Pulsa "Ejecutar consulta" para ver las coincidencias.
IMPORTANTE

La importancia de ON

Con ON

SELECT * FROM empleado JOIN departamento ON empleado.codigo_departamento = departamento.codigo;

Sin ON

SELECT * FROM empleado JOIN departamento;
¿Cuál de las dos consultas produce un producto cartesiano?
ALTERNATIVA

INNER JOIN con USING

Se utiliza cuando la columna que relaciona las tablas tiene el mismo nombre en ambas.

Con ON

... JOIN departamento ON empleado.codigo_departamento = departamento.codigo_departamento;

Con USING

... JOIN departamento USING (codigo_departamento);
Pulsa para comprobar cuándo podemos usar USING.
AUTOMÁTICO

NATURAL JOIN

Busca automáticamente columnas con el mismo nombre y las utiliza para relacionar las tablas.

SELECT * FROM empleado NATURAL JOIN departamento;
Pulsa el botón para descubrirlo.
Precaución: úsalo solo cuando estés seguro de que los nombres iguales representan la relación que necesitas.
